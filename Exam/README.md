# Экзамен

Отдельной экзаменационной формы у модуля нет: итоговая аттестация — защита
проекта, см. [Project](../Project/README.md).

Такое решение принято сознательно. Проверять теорию отдельным экзаменом в
модуле, где студент шестнадцать недель делает продукт и каждые две недели
защищает сделанное в разговоре, значит измерять то же самое второй раз и
хуже: на приёмке видно, понимает ли человек свою работу, а на экзамене —
помнит ли он определения.

Если учебный план требует экзамен как форму контроля, ею оформляется та же
защита проекта.
