# Модуль M5. ТЕСТИРОВАНИЕ И МЕТРИКИ

**Сроки:** Недели 11–12  
**Вес модуля:** 34 баллов  
**Форма аттестации:** защита работы на приёмке (разговор с командой)

## Задача модуля

Ответить цифрами: North Star против цели, финальные evals против критериев успеха, система против нагрузки, продукт против атак. Спринт доказательств.

**Вопросы на приёмке.** Задаются вживую, ответ студента оценивает преподаватель:

- Спроси, попали ли в цель по главной метрике продукта и что это значит для пользователя.
- Возьми любую боль из описания продукта и попроси показать на проде, как она закрывается.
