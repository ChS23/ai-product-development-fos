# Программное обеспечение

Конкретный стек модулем не предписывается: выбор инструментов и его
обоснование — часть работы команды, которая защищается на приёмке.

Что требуется по существу:

| Что нужно | Зачем |
|---|---|
| Python | язык лабораторных |
| git и GitHub | сдача идёт pull request |
| Docker и Docker Compose | продукт поднимается одной командой |
| доступ к языковой модели по API | любой OpenAI-совместимый провайдер |
| хостинг для публичного адреса | продукт должен открываться по ссылке |

Всё остальное — веб-фреймворк, база, средства наблюдаемости, библиотеки
для работы с моделями — команда выбирает сама и объясняет выбор.

Автоматическая проверка сдач и ведение приёмки обеспечиваются отдельной
платформой, в состав настоящего фонда она не входит.
