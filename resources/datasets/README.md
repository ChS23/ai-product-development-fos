# Наборы данных

Готовых наборов модуль не поставляет — и это часть замысла.

Каждая команда собирает данные под свою задачу сама: снимает, выгружает
своё, договаривается со знакомыми, берёт открытые источники. Умение
добыть данные и честно сказать, чем добытое хуже настоящего, — один из
проверяемых результатов обучения, а не подготовительный этап.

Каталог тем на [сайте курса](https://sii.sergeivolchkov.ru/projects) для
каждой темы содержит раздел о доступности данных с четырьмя вариантами:
команда добывает сама, есть открытые источники, придётся строить
синтетику, нужен партнёр.

## Что проверяется

- откуда взялись данные и кто размечал их руками;
- сколько примеров и почему столько;
- чем собранный набор отличается от того, с чем система встретится в
  реальности.

Последний вопрос обязателен на приёмке: набор из двадцати примеров,
собранных за вечер, — нормальное начало, если команда понимает его
границы.
