# Учебные материалы

Основной источник — [материалы курса](https://sii.sergeivolchkov.ru/materials):
разделы привязаны к модулям и содержат разбор приёмов с примерами.

Учебника в классическом смысле у модуля нет и не предполагается: предмет
меняется быстрее, чем издаются книги. Материалы курса версионируются
вместе с критериями, поэтому расхождения между тем, что читают, и тем, что
проверяют, не возникает.
