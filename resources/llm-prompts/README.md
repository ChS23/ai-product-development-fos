# Промпты

Библиотеки готовых промптов модуль не даёт: промпт — это часть решения
команды, и подобранный за неё снял бы главную работу роли AI Engineer.

Что вместо этого проверяется:

- промпты вынесены из кода и версионируются вместе с ним;
- изменение промпта прогоняется через evals, а не оценивается на глаз;
- команда объясняет, почему промпт такой, и что стало хуже при изменении.

Разбор приёмов и типовых ошибок — в
[материалах курса](https://sii.sergeivolchkov.ru/materials).
