# Задачники

Отдельного задачника нет: работа модуля — один сквозной проект, а не набор
упражнений.

Роль задачника выполняет каталог тем на
[сайте курса](https://sii.sergeivolchkov.ru/projects): сорок с лишним тем,
каждая с разбором — чей это рабочий процесс, почему задача не решается
одним вызовом модели, что считать успехом и что здесь будут ломать.

Отдельным блоком там же идут задачи от бизнеса — темы, у которых есть
реальный заказчик.
