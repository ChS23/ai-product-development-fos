# Бенчмарки

Внешних бенчмарков модуль не использует.

Качество измеряется на данных задачи: команда сама определяет, что считать
хорошим ответом, собирает эталонный набор и защищает выбор метрики на
приёмке. Готовый бенчмарк ответил бы за неё на главный вопрос — что здесь
считать успехом, — а именно его студент должен научиться задавать.

Публичные бенчмарки упоминаются в материалах курса как способ сравнивать
модели при выборе, но в оценивание не входят.
