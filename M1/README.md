# Модуль M1. ИНИЦИАЦИЯ ПРОЕКТА

**Сроки:** Недели 1–2  
**Вес модуля:** 29 баллов  
**Форма аттестации:** защита работы на приёмке (разговор с командой)

## Задача модуля

Выбрать сегмент, понять его боли, договориться о словах и заложить фундамент: к концу спринта у команды общий язык, проверяемые гипотезы, работающий CI и прод с заглушкой.

**Вопросы на приёмке.** Задаются вживую, ответ студента оценивает преподаватель:

- Спроси, кто конкретно из знакомых команде людей попадает в сегмент — по имени и обстоятельствам.
- Возьми термин из глоссария и попроси объяснить, не пользуясь словами из определения.
- Спроси по любой гипотезе: какой результат заставит признать её ложной.
- Возьми любой критерий успеха и спроси, кто и чем замерит его в понедельник утром: какой командой или где посмотреть число.
