## Главное в двух абзацах

Модуль устроен вокруг командного проекта, который живёт весь семестр.
Студенты не выполняют семь отдельных заданий — они семь раз сдают одну и ту
же систему на разных стадиях зрелости. Это меняет и работу преподавателя:
он не проверяет работы, а принимает этапы у команды, которая помнит, что
обещала две недели назад.

Проверка разделена на два слоя. Форма — есть ли артефакт, запускается ли
система, отвечает ли публичный адрес — проверяется автоматически.
Понимание проверяет только человек в разговоре, и для этого у каждого
критерия есть вопрос к защите с признаком хорошего ответа. Второй слой
нельзя автоматизировать: он существует ровно потому, что артефакт бывает
на месте, а понимания за ним нет.
